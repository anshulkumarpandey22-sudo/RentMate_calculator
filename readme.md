# Easy Rent Calculator

Hey there!  Welcome to my Easy Rent Calculator. I built this for a school project to solve a very real, everyday problem: figuring out exactly who owes what when rent and utility bills are due. No more awkward math at the kitchen table!

##  What It Does

This is a super simple command-line script that calculates exactly how much each roommate needs to pay. 

* **Takes your roommates' names:** You just type them in, separated by commas[cite: 2].
* **Calculates the total:** It adds up your total rent and utilities[cite: 2].
* **Does the math:** It divides the total expenses evenly by the number of valid roommates entered and tells you exactly what everyone owes down to the cent[cite: 2].

##  How to Run It

Want to try it out? It's really easy to get running on your computer.

1. Make sure you have Python installed.
2. Download the `main_2.py` file to your computer[cite: 2].
3. Open your terminal or command prompt, navigate to where you saved the file, and run:

bash
python main_2.py
